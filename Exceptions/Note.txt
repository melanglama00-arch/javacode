Best Practicesfor Exception handling
1-> catch specific Exception
2-> never Leave Catch blocks empty
3-> Use Meaningful Error Message
4-> Do not use exception for normal flow control
5-> Log the Exception (java.util.logging),LOg4j, SLF4j
6-> Use finally or Try-with resources
7-> Throw Exceptions with Clear Context-> throw new Exceptio
